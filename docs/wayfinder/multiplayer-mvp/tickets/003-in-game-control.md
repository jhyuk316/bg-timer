## Question

전체 보드를 공유하면서 담당 말, 현재 턴, 연결 상태, 방장 제어를 각 기기에서 어떻게 표현하고 충돌 시 어떤 반응을 보여줄지 결정한다.

## Resolution

- 모든 기기에 전체 플레이어 보드와 타이머를 표시한다.
- 방장과 게스트 모두 소유 기기나 연결 상태와 관계없이 모든 플레이어 말을 조작할 수 있다.
- 게스트 연결이 끊겨도 게임을 자동으로 멈추지 않는다.
- 연결이 끊긴 게스트의 말에는 상태를 표시하며, 남은 기기 참가자가 조작해 게임을 계속할 수 있다.
- 같은 게스트가 재접속하면 기존 말 배정과 준비 정보를 복구한다.
- 거의 동시에 발생한 턴 조작은 Firebase에서 먼저 확정된 변경만 적용하고 모든 기기가 확정 상태로 수렴한다.
- 일시정지 기능은 두지 않는다. 게임 시작부터 종료까지 플레이어 시간이 아닌 모든 구간은 운영시간으로 누적한다.
- 게임 종료는 방장만 조작한다.
