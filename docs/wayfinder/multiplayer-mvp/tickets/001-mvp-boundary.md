## Question

첫 멀티플레이 버전이 어디까지 동작해야 완성으로 볼지, 게임 화면과 첫 진입 화면은 어떤 원칙을 사용할지 결정한다.

## Resolution

- 방 생성, QR·방 코드 참가, 기기별 복수 말 선택, 모든 말 조작, 새로고침 복귀, 게임 종료와 통계까지 포함한다.
- 기존 싱글 모드는 그대로 유지한다.
- 모든 기기에 동일한 전체 보드를 표시하고 모든 기기 참가자가 모든 플레이어 말을 조작할 수 있게 한다.
- 기존 설정 화면 상단에서 `싱글 | 멀티` 모드를 전환한다.
- Firebase 플레이 기록, 관전자, 방장 이전, 공개 방, 계정 로그인은 제외한다.
