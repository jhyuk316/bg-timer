# 방 기반 게임의 시간 알림 요구사항 검토

상태: 검토 필요

2026-10-01 문서 점검에서 PRD의 시간 경고·TTS 요구사항과 현재 방 기반 게임 흐름의 차이를 확인했다. `js/app.js`에서 시간 경고 및 TTS 호출을 확인하지 못했으므로 완료된 기능으로 안내하지 않는다.

## 결정할 사항

- 남은 시간 차감 방식에 시간 전환·잔여 시간·패널티 알림을 복원할지 결정한다.
- 여러 기기에서 같은 음성이 중복 재생되지 않도록 알림 주체를 정한다.
- 플레이 시간 누적에는 차감 방식의 잔여 시간 알림을 적용하지 않는다.

복원 범위가 확정되면 별도 구현 작업으로 진행한다.
