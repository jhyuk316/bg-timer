# 심플 타이머를 기본값으로 전환

상태: TODO

멀티플레이 MVP 계획과 별개로 진행할 타이머 UX 개선 작업이다.

## 결정

- 첫 사용의 직관성을 AP 교정 효과보다 우선한다.
- 심플 모드를 기본 타이머 방식으로 사용한다.
- 심플 모드에서는 플레이어별 소비 시간만 누적해 표시한다.
- 메인 시간, 턴 딜레이, 시간 소진 후 추가 시간과 패널티 기능은 기본 화면에서 제거한다.
- 기존 기능은 삭제하지 않고 `고급 설정` 안의 고급 타이머로 제공한다.

## 구현 시 확인할 사항

- 기존 사용자의 저장된 타이머 설정을 심플 모드와 고급 타이머 중 어느 쪽으로 복원할지 결정한다.
- 설정 화면, 게임 화면, 통계와 히스토리에서 심플 모드에 불필요한 값을 숨긴다.
- 심플 모드 게임 기록에는 플레이어별 누적 소비 시간과 턴 수를 남긴다.
- 싱글과 멀티 모두 같은 타이머 모드 정의를 사용한다.
