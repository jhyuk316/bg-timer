# 플레이 시간 누적을 기본 타이머 방식으로 전환

상태: 완료 (PR #3, b6e1420)

2026-10-01 문서 점검: 기본 설정과 새 방은 simple을 사용하며, 타이머 방식이 없는 이전 설정도 플레이 시간 누적으로 복원한다. 현재는 방 기반 게임만 제공한다.

멀티플레이 MVP 계획과 별개로 진행할 타이머 UX 개선 작업이다.

## 결정

- 첫 사용의 직관성을 AP 교정 효과보다 우선한다.
- 플레이 시간 누적을 기본 타이머 방식으로 사용한다.
- 플레이 시간 누적에서는 플레이어별 플레이 시간만 누적해 표시한다.
- 메인 시간, 턴 딜레이, 시간 소진 후 추가 시간과 패널티 기능은 기본 화면에서 제거한다.
- 기존 기능은 삭제하지 않고 `타이머 방식`에서 남은 시간 차감으로 제공한다.

## 완료 기준

- 타이머 방식이 없는 기존 설정은 플레이 시간 누적으로 복원한다.
- 설정 화면, 게임 화면, 통계와 히스토리에서 플레이 시간 누적에 불필요한 값을 숨긴다.
- 플레이 시간 누적 게임 기록에는 플레이어별 누적 플레이 시간과 턴 수를 남긴다.
- 현재 방 기반 게임에 같은 타이머 방식 정의를 사용한다.
