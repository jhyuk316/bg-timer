# 플레이 기록 이미지 등록과 외부 저장소 연동

상태: TODO (보류)

플레이 기록에 이미지를 붙일 수 있도록 이미지 파일은 외부 저장소에 올리고, Firebase Realtime Database에는 파일 경로나 URL만 저장한다.

## 구현 전 결정할 사항

- 이미지를 앱 운영자만 등록할지, 게임 참가자도 직접 올릴지 결정한다.
- 무료 저장소의 용량·전송량·업로드 제한과 이미지 링크 유지 조건을 비교한다.
- 사용자 업로드를 허용한다면 업로드 권한, 파일 크기·형식, 삭제와 악용 방지 방식을 정한다.
- 기록 소유자가 바뀌거나 기록을 삭제할 때 이미지 파일을 어떻게 처리할지 정한다.

현재 플레이 기록 Firebase 저장 PR의 범위에는 포함하지 않는다.
