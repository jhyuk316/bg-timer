# 종료 후 게임 선택

브랜치: codex/game-catalog-selection. A 전체 화면 검색 구현 중.

- 종료 후 방장이 선택하며 건너뛰기 가능. 직접 입력 허용.
- 전체 10,000개 한영 제목·연도 검색. 정확/접두/부분/초성 순서, 최대30개.
- 한글 조합 중에도 결과를 갱신하며 `브라ㅅ` 같은 미완성 입력은 자모 단위로 추가 매칭한다. 입력창 자체는 교체하지 않는다.
- 최근 선택10개는 기기 localStorage에 저장.
- 방의 playedGame은 방장만 종료 후 쓰고 참가자는 읽는다. 각 UID 기록에 읽을 때 복사한다.
- 참가자가 결과를 떠나도 기록을 다시 읽으면 반영된다. 방이 삭제되거나 참가자 접근권한이 사라지기 전 읽지 못한 기록은 갱신할 수 없다.
- 정규화 WebP 3000개를 images/games에 포함하고 게임 ID로 연결했다. 나머지7000개는 제목만 표시한다. 결과에 보이는 이미지만 lazy loading하며 설치 시 전체 이미지를 캐시하지 않는다. 공개 이미지 재배포 권한은 별도 확인 필요.
- Firebase 규칙 배포·방장/손님 실제 동기화·모바일 키보드 QA는 미완료.
- 검증: 단위 테스트33개 통과, 목록10000개/이미지3000개 경로와 긴 변512px 확인. 운영 규칙 배포는 승인 검토에서 차단되어 실행하지 않았다.
